# Appendix A — Minimal-Edit Correction Instructions

The following instructions defined the minimal-edit correction policy used by the fixed grammatical error correction model.

**System:** For the provided text, you will correct the English as follows:

1. **First, correct all spelling mistakes.**
   - Do not change spelling between different Englishes, such as US English and UK English.
   - Do not mark spelling changes with brackets or other notation.

2. **Do not change grammar between different Englishes.**
   - Correct sentences that are clearly wrong, confusing, or highly unusual in English usage.
   - Do not change sentences that are acceptable but only slightly unusual.
   - Do not substitute words (e.g., “because”/“since,” “but”/“however,” or “next”/“afterward”) unless the original meaning is incorrect.

3. **Join or split sentences when necessary.**
   - Join sentences when doing so produces a more natural construction.
   - Split sentences when a sentence is unnaturally long.

4. **Bracket optional added words.**
   - If an added word is optional and its removal would not make the sentence ungrammatical, place it in brackets.
   - Do **not** bracket required words.
   - Only bracket added words when they are genuinely optional.

### Example

**Input:** `I wents to hospital tooday.`

**Output:** `I went to (the) hospital today.`

Here, “the” is optional and is therefore bracketed.

# Appendix B — Computational Measurement Pipeline

The computational pipeline was applied to the same held-out set of 1,000 learner texts evaluated in the previous grammatical error correction study. These texts were not included in the 2,617 examples used for fine-tuning. Each learner text was paired with one minimally corrected counterpart generated by the fixed fine-tuned model.

GLEU and the ERRANT edit count were calculated from each learner–correction pair. Perplexity was calculated separately for the learner and corrected texts using a fixed GPT-2 model, and ΔPPL was calculated as the difference between the two scores. Syntactic complexity was calculated from the original learner texts only using the L2 Syntactic Complexity Analyzer (L2SCA).

## Variable Naming

The manuscript uses readable display labels, while the analysis files use syntactically valid column names.

| Manuscript label | Analysis variable | Interpretation |
|---|---|---|
| GLEU | `GLEU` | Similarity between the learner text and its minimally corrected counterpart |
| Total errors | `Total_errors` | Number of ERRANT-aligned edits |
| PPL | `text_ppl` | Perplexity of the original learner text |
| Corrected PPL | `corrected_ppl` | Perplexity of the minimally corrected text |
| ΔPPL | `ppl_delta` | `text_ppl − corrected_ppl` |
| MLT | `text_MLT` | Mean length of T-unit |
| MLC | `text_MLC` | Mean length of clause |
| CN/C | `text_CN_C` | Complex nominals per clause |
| CN/T | `text_CN_T` | Complex nominals per T-unit |

## Example Python Pipeline

```python
import os
import subprocess

import errant
import pandas as pd
import torch
from nltk.translate.gleu_score import sentence_gleu
from transformers import GPT2LMHeadModel, GPT2TokenizerFast


# ==============================================================================
# 1. PATHS AND SETUP
# ==============================================================================

ORIGINAL_DIR = "original_texts/"
CORRECTED_DIR = "corrected_texts/"
L2SCA_OUTPUT = "l2sca_output.csv"
FINAL_OUTPUT = "df_caf_final.csv"

# Change this value only if the selected L2SCA implementation uses a
# different identifier-column name.
L2SCA_ID_COLUMN = "file"

annotator = errant.load("en")

device = "cuda" if torch.cuda.is_available() else "cpu"

ppl_model = GPT2LMHeadModel.from_pretrained("gpt2").to(device)
ppl_tokenizer = GPT2TokenizerFast.from_pretrained("gpt2")
ppl_model.eval()


# ==============================================================================
# 2. METRIC FUNCTIONS
# ==============================================================================

def get_ppl(text):
    """
    Calculate model-relative perplexity for a completed text.

    Lower values indicate greater distributional predictability under
    the fixed GPT-2 language model.
    """
    encodings = ppl_tokenizer(text, return_tensors="pt")
    input_ids = encodings.input_ids.to(device)

    with torch.no_grad():
        outputs = ppl_model(input_ids, labels=input_ids)

    return torch.exp(outputs.loss).item()


def get_gleu(original, corrected):
    """
    Calculate GLEU similarity between the learner text and its
    minimally corrected counterpart.

    Multiplication by 100 places the result on the 0–100 scale used
    in the manuscript and descriptive tables.
    """
    score = sentence_gleu(
        [original.split()],
        corrected.split()
    )

    return 100 * score


def get_edit_count(original, corrected):
    """
    Count the ERRANT-aligned edits required to transform the learner
    text into its minimally corrected counterpart.
    """
    original_parsed = annotator.parse(original)
    corrected_parsed = annotator.parse(corrected)

    edits = annotator.annotate(
        original_parsed,
        corrected_parsed
    )

    return len(edits)


# ==============================================================================
# 3. ACCURACY AND PERPLEXITY MEASURES
# ==============================================================================

records = []

for filename in sorted(os.listdir(ORIGINAL_DIR)):
    if not filename.endswith(".txt"):
        continue

    original_path = os.path.join(
        ORIGINAL_DIR,
        filename
    )

    corrected_path = os.path.join(
        CORRECTED_DIR,
        filename
    )

    if not os.path.exists(corrected_path):
        raise FileNotFoundError(
            f"No corrected counterpart found for {filename}"
        )

    with open(
        original_path,
        "r",
        encoding="utf-8"
    ) as file:
        original = file.read().strip()

    with open(
        corrected_path,
        "r",
        encoding="utf-8"
    ) as file:
        corrected = file.read().strip()

    gleu = get_gleu(
        original,
        corrected
    )

    total_errors = get_edit_count(
        original,
        corrected
    )

    text_ppl = get_ppl(original)
    corrected_ppl = get_ppl(corrected)
    ppl_delta = text_ppl - corrected_ppl

    records.append({
        "file": filename,
        "GLEU": gleu,
        "Total_errors": total_errors,
        "text_ppl": text_ppl,
        "corrected_ppl": corrected_ppl,
        "ppl_delta": ppl_delta
    })

caf_metrics = pd.DataFrame(records)


# ==============================================================================
# 4. SYNTACTIC COMPLEXITY: L2SCA
# ==============================================================================

# Syntactic complexity was calculated from the original learner texts only.
# The command below is illustrative and should be adapted to the exact
# L2SCA implementation used in the original analysis.

subprocess.run(
    [
        "python3",
        "L2SCA/analyzeFolder.py",
        ORIGINAL_DIR,
        L2SCA_OUTPUT
    ],
    check=True
)

l2sca = pd.read_csv(L2SCA_OUTPUT)

required_l2sca_columns = {
    L2SCA_ID_COLUMN,
    "MLT",
    "MLC",
    "CN/C",
    "CN/T"
}

missing_l2sca_columns = (
    required_l2sca_columns - set(l2sca.columns)
)

if missing_l2sca_columns:
    raise ValueError(
        "Missing required L2SCA columns: "
        f"{sorted(missing_l2sca_columns)}"
    )

complexity_metrics = (
    l2sca[
        [
            L2SCA_ID_COLUMN,
            "MLT",
            "MLC",
            "CN/C",
            "CN/T"
        ]
    ]
    .rename(
        columns={
            L2SCA_ID_COLUMN: "file",
            "MLT": "text_MLT",
            "MLC": "text_MLC",
            "CN/C": "text_CN_C",
            "CN/T": "text_CN_T"
        }
    )
)


# ==============================================================================
# 5. COMBINED CANDIDATE-METRIC DATASET
# ==============================================================================

final_data = caf_metrics.merge(
    complexity_metrics,
    on="file",
    how="left",
    validate="one_to_one"
)

required_final_columns = [
    "file",
    "GLEU",
    "Total_errors",
    "text_ppl",
    "corrected_ppl",
    "ppl_delta",
    "text_MLT",
    "text_MLC",
    "text_CN_C",
    "text_CN_T"
]

final_data = final_data[required_final_columns]

final_data.to_csv(
    FINAL_OUTPUT,
    index=False
)

print(
    f"Wrote {len(final_data)} rows to {FINAL_OUTPUT}"
)
```

**Note.** This code documents the metric-generation procedure without reproducing local paths from the original analysis environment. GLEU is reported on a 0–100 scale. `Total_errors` represents the number of ERRANT-aligned edits between the same text pair. Raw perplexity (`text_ppl`) represents model-relative distributional predictability of the learner text, while `ppl_delta` is calculated as `text_ppl − corrected_ppl`. The corrected-text perplexity was used to derive ΔPPL but was not entered as a separate candidate Fluency indicator. L2SCA was applied only to the original learner texts.

# Appendix E — CFA and SEM Analysis Script

The following R script performs the analyses reported in the manuscript:

1. screening of the three-indicator Complexity model;
2. screening of the expanded four-indicator model including CN/T;
3. screening of the Accuracy and Fluency indicator pairs;
4. testing of latent Fluency within the full SEM;
5. estimation of the final model using ΔPPL; and
6. estimation of the parallel final model using raw PPL.

The two-indicator pair models are identified by fixing their loadings to equal magnitudes. The loading for `Total_errors` is negative because higher GLEU and fewer edits both indicate greater correction-referenced Accuracy.

report_fit <- function(
    fit,
    label
) {
    cat(
        "\n============================================================\n"
    )

    cat(
        label,
        "\n"
    )

    cat(
        "============================================================\n"
    )

    if (inherits(fit, "try-error")) {
        cat(
            "Model estimation failed.\n"
        )

        return(
            invisible(NULL)
        )
    }

    converged <- lavInspect(
        fit,
        "converged"
    )

    cat(
        "Converged:",
        converged,
        "\n"
    )

    print(
        summary(
            fit,
            standardized = TRUE,
            fit.measures = TRUE
        )
    )

    parameters <- parameterEstimates(
        fit,
        standardized = TRUE
    )

    residual_variances <- parameters %>%
        filter(
            op == "~~",
            lhs == rhs
        ) %>%
        select(
            lhs,
            est,
            std.all
        )

    cat(
        "\nResidual variances:\n"
    )

    print(
        residual_variances
    )

    heywood_flag <- (
        !converged ||
        any(
            residual_variances$est < 0,
            na.rm = TRUE
        )
    )

    cat(
        "\nHeywood or instability flag:",
        heywood_flag,
        "\n"
    )

    invisible(
        list(
            converged = converged,
            heywood_flag = heywood_flag,
            parameters = parameters,
            residual_variances = residual_variances
        )
    )
}


get_standardized_covariance <- function(
    fit,
    variable_1,
    variable_2
) {
    parameters <- parameterEstimates(
        fit,
        standardized = TRUE
    )

    covariance <- parameters %>%
        filter(
            op == "~~",
            lhs != rhs,
            (
                lhs == variable_1 &
                rhs == variable_2
            ) |
            (
                lhs == variable_2 &
                rhs == variable_1
            )
        )

    if (nrow(covariance) == 0) {
        return(
            NA_real_
        )
    }

    covariance$std.all[1]
}

**Note.** The three-indicator Complexity model uses MLT, MLC, and CN/C. The expanded screening model adds CN/T. Accuracy is retained as the observed GLEU score after screening established its redundancy with the ERRANT edit count. The final SEMs compare two alternative observed Fluency indicators: ΔPPL and raw PPL. This comparison reflects the manuscript’s conclusion that the choice of perplexity operationalization changes how Fluency relates to Accuracy and Complexity.
